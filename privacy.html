Privacy policy

This policy covers Ali’s Personal Google API Client, operated by Ali Al-Alak for personal access to his own Google accounts through rclone and ad hoc API tools.

Data accessed and why

The client uses Google OAuth to authorize personal tasks. Depending on the scopes approved and commands run, tools may access Google Drive files, file contents and metadata, or data from other explicitly authorized Google APIs. OAuth access and refresh tokens allow those tools to perform the authorized tasks. The client does not request or store Google account passwords.

Data is used only to carry out my own requested operations, such as file transfers, backups, synchronization, and personal automation. This client is not intended to collect data from other people’s Google accounts.

Storage and retention

Tokens and tool configuration are stored in the environments where I run the tools. Downloaded files, backups, and any tool logs may remain on my devices or in storage destinations I configure until I delete them. Retention depends on the task and tool; there is no separate hosted application database.

Tokens are sensitive credentials and must be protected using appropriate filesystem permissions and device security. They must not be committed to this public repository.

Sharing and use restrictions

I do not sell Google user data or use it for advertising. Data is transferred only as needed for the personal operations I initiate, including transfers to storage providers I explicitly configure. Those providers process data under their own terms and policies.

Ali’s Personal Google API Client’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Revoking access and deleting data

I can revoke the client’s authorization at any time through Google Account connections. I can remove locally stored tokens and configuration using the relevant tool, and delete downloaded files, logs, and backups from each destination where they are stored. Revoking authorization does not automatically delete previously copied data.

This website

This is a static information site hosted on GitHub Pages. It has no sign-in form, analytics scripts, tracking cookies, or embedded third-party assets. It does not receive Google account data or OAuth credentials. GitHub may process technical request information, such as IP addresses, to operate and secure hosting; see the GitHub Privacy Statement.

Changes and contact

This policy may be updated as the personal tools change. The effective date above will be updated when the policy changes. Questions or data-handling concerns can be raised through a repository issue. Issues are public; do not post tokens, credentials, or personal account data.
